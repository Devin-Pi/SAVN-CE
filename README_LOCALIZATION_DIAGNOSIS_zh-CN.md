# 定位候选离线／在线差异诊断（2026-11-08）

本轮诊断已完成。没有训练模型，没有调整0.5活动阈值，没有向导航策略提供定位结果。以下结果只针对第97轮候选、episode `1000000008`及其官方`train/chair.wav`，不能外推到所有类别或所有SoundSpaces版本。

## 主要结论

**0.25秒是采集步长，现有模型的训练和在线推理窗均为10秒。** 但窗口中的起声位置、播放方式和电平确实存在明显差异；模型对这些变化非常敏感。静止且有充足声音时也会失败，排除了“只是运动”或“只是窗内没声音”的解释。不能通过给在线输入加50毫秒静音解决这个问题：起声调整在不同片段上有相反效果。

离线指标的适用范围是固定接收器、同房间、几何直达可见、经过非静音选片／重触发和全局电平调整的合成录音。chair训练／验证／测试使用同一官方源WAV，场景分开；这些数据不能证明源录音独立泛化。10秒训练窗全部从各合成文件的起点开始，起声被安排在约40–90毫秒；原生在线滚动窗会截取已经在播放的声音，也会包含真正停声后的片段。这项训练／在线分布差异得到下面的隔离实验支持。

## 四组主对照

这里的“检出率”是**有效活动帧上正确类别的解码召回率**，不含20°要求，不能称为DSF的F20或SELD。活动／忽略规则沿用训练数据的干声到达占比与湿声可闻阈值；尾声单独排除。源位置只用于推理完成后的几何误差评估。

|条件|有效活动帧（含重叠）|原生输入chair检出率|统一训练电平后|原生条件检出时的方向误差均值|
|---|---:|---:|---:|---:|
|静止＋持续|882|109/882 = 12.4%|33.0%|4.65°|
|静止＋间歇|441|87/441 = 19.7%|31.7%|7.07°|
|运动＋持续|882|10/882 = 1.1%|22.4%|118.58°|
|运动＋间歇|441|91/441 = 20.6%|38.8%|98.03°|

方向误差只对成功解码出chair的活动帧计算，漏检不算0°；不能用条件误差代替完整定位指标。运动结果方向也不可靠。按直线源位置计算的误差不证明混响中最强入射方向就是直达方向。

统一电平不能作为直接修复：间歇静止条件有效背景误报由38/292（13.0%）升至70/292（24.0%）；运动间歇由34/297（11.4%）升至75/297（25.3%）。这些是训练活动／忽略规则下的背景帧统计，不是把所有尾声都当作静音。

原生W电平约−45.2至−35.0dBFS，部分低于训练指定的−35至−20dBFS。源预处理确有差别：原生librosa重采样／功率归一化，相对训练polyphase源的最佳统一系数约1.50046、相关系数0.999277、对齐后相对RMSE约3.80%。但把原生源版本代入**相同选片、起止、RIR与最终电平**的密集合成，三个种子的有效活动帧召回仍全部100%；现有证据不支持将这点差异认定为主要根因。

## 固定RIR与窗口起声：关键隔离结果

固定接收器、第一条实际RIR、朝向与`−27.5dBFS`后，原样连续源的0秒起窗检出100%，3秒及6秒起窗均0%。将后两个窗口分别改到训练电平范围的−35和−20dBFS仍为0%。因此增益不足不是完整解释。

用同一场景、同一源WAV、同一RIR重新执行训练中的非静音选片／重触发，三个种子均100%。进一步限制到**各自原来的10秒干声片段**，得到：

|原干声片段起点|该片段从零历史重新卷积|相同片段延迟50ms并加5ms起声淡入|只用该片段进行训练式密集选片|
|---|---:|---:|---:|
|0秒|100%|4.2%|100%|
|3秒|0%|100%|100%|
|6秒|0%|100%|100%|

这是诊断重合成：不改变模型、RIR、类别阈值或最终W电平。重新卷积去掉前窗历史；50ms对照同时改变起声位置及淡入并截去最后50ms，因此不是数学意义上只平移所有条件不变。结果证明候选对窗口起声／时间对齐非常敏感，但不证明某一个神经网络模块是唯一原因。

模型内部按时间维度做逐频带均值／标准差归一化；这种操作可能与静态方向、活动边界耦合，**目前只是机制假设**，尚未通过独立归一化消融确证。不能以“补50ms静音”上线，因为它也把另一个片段从100%降到4.2%。

## 几何和平滑的边界

独立碰撞与实际导出的声学几何检查显示，初始接收器和源都位于房间7、距离约3.112米，直达可见。64个受测姿态的声学直达线段均畅通；其中18个姿态可明确归为与源同房间，其余不满足该同房间证书。初始、最近和末姿态的独立direct-only RIR均非零。未使用有问题的`sourceIsVisible()`作为判定，因此本次不能直接归因于遮挡／绕射。

关闭temporalCoherence没有一致恢复：种子7静止持续原生召回从6.8%变为5.1%，运动持续从0.68%仍为0.68%；间歇条件也不单调。该开关会改变RIR及蒙特卡洛结果，单一种子不是完整平滑因果效应估计。未修改原在线引擎设置。
