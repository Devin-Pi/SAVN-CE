# Localization expert 适用性分析

结论：当前权重可作为受限条件下的研究原型，但尚不适合作为覆盖全部21类的可靠AVN localization expert。没有接入或替换在线Agent。

已按用户新要求在95个完整epoch后结束，最佳权重来自第95轮。验证记录SELD=0.271348、F20=0.694738、LE=33.0386°；独立复算SELD=0.271074。test SELD=0.255703、F20=0.708488、LE=32.7548°、LR=0.718645。

原decoder另有两轨可合并且第三轨未激活时丢弃输出的历史行为；test统计95个受抑制的类别帧，其中88帧GT相应类活动。本次为保持DSF兼容没有修改，当前三个零检出类的raw分数也低于阈值，因此不能将它们的全部问题归因于该合并行为。

test的36条无事件clip均未产生输出；这是本协议的小样本结果，不是对任意现实背景都无误报的保证。

## 验证边界和未解决事项

- 数据为known-sound/unseen-scene，每类只有一个官方WAV家族。分类成绩不能证明对未见独立音源泛化。
- 训练/测试是同房间LOS、静态单源、10秒FOA。未验证移动Agent的跨位姿音频窗口、短窗口、跨房间/NLOS、多声源和实际导航成功率。
- 活动分数未校准，模型不预测距离；当前尚不支持将输出直接视为可靠STOP依据。
- 验证冷加载分数与原记录有约0.000275 SELD差异，未完全隔离原因。原加载器和独立加载器首批输出一致；保留所有复查证据及明确容差，不宣称逐位复现。
- 当前结果没有直接与原论文13类DCASE预训练或视听SELD=0.354比较。

下一阶段宜先从训练/验证集检查弱类的有效监督时长、活动/类别学习及阈值校准，再单独设计在线AVN评估。本次未开展新训练、阈值搜索或复杂场景开发。
